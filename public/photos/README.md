# Fotografías personales

Coloca aquí COPIAS de tus fotografías; conserva los originales por separado.
En `public/data/cv.json`, usa rutas como `photos/perfil.webp` o `photos/portada.jpg`, sin `/` inicial.
Completa `alt` con una descripción real de la imagen. No uses las fotos de ejemplo de `assets/img` como fotos tuyas.

Sugerencias: perfil de unos 800 px; portada de unos 1600–1920 px; proyectos de unos 1000 px. Usa WebP o JPEG comprimido; evita archivos de varios MB. Los recortes se realizan con `object-fit: cover`, sin deformar la foto. Ajusta `object-position` en `src/styles.css` si necesitas mover el encuadre.
